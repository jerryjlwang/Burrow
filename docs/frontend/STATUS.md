- The debug panel (settings, Developer panel) is the quickest way to see every state on a real page.
- After a rebuild, reload the extension card at chrome://extensions, then reload open tabs. The new tab page, popup and parent page read fresh files from `extension/dist` on every open, but Chrome only re-reads the content script (`content.js`, the rabbit on web pages) when the card is reloaded, so a web page can show an older rabbit than the meadow until then. `npm run dev` keeps `dist` fresh (a dev build) on every source change.
- Known simplification: `thinking.exit` is `aha` on every exit, so a barge-in during thinking shows the bulb for two thirds of a second before listening.
