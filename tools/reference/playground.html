Three characters, two browser windows

A working sketch of the Wonderland OS extension. The characters sit on top of a web page, talk to each other, react while the others speak, perch on parts of the page, and travel between windows down a rabbit hole. Click any character to say hello.

Why did castles have moats?

A moat is a deep, wide ditch dug around a castle. Many were filled with water, but plenty were dry.

Attackers wanted to dig tunnels under the walls to make them collapse. A moat made that nearly impossible.

It also kept siege towers and battering rams away from the gate.

How this becomes a Chrome extension

  1. A content script adds one invisible layer on top of every page, inside a shadow root so the page's own styles can't break it. The characters live in that layer. Everything except the characters lets clicks pass through.
  2. The background worker owns the pet's state and the connection to your server, so the pet survives tab switches and page loads. Only the active tab draws it, which means it follows the kid from tab to tab for free.
  3. Because the layer is inside the page, characters can read the page. The rabbit above lands on the real position of the headline. An operating system overlay can't do that.
  4. The teach screen and the brain map go in Chrome's side panel. The microphone for Deepgram runs from an extension page, since a content script would need permission again on every site.
  5. The jump between laptops is a message through your server. The sending side plays hole_open, dive, then closes the hole. The receiving side opens a hole, loops hole_wait until the handoff lands, then plays dive backwards.
